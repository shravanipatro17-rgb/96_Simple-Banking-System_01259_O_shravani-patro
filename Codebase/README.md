Project Description - Simple Banking System

*PS No.:* 96
*Project Title:* Simple Banking System
*Course:* http://B.Tech Computer Science and Engineering in association with IBM - First Semester
*Language:* Python 3

*Problem Statement:*
Create a banking application that lets customers open an account, deposit, withdraw, transfer money and check balance, with all data stored in a file.

*Project Description:*
The Simple Banking System is a console-based application developed in Python 3. It simulates the basic operations of a real bank. The user can create a new bank account, deposit money, withdraw money, transfer money from one account to another, and check the balance of any account.

All account details like Account Number, Customer Name and Balance are stored in a text file named .py simple banking system.Every  time the program runs, it loads the data from this file, and after every transaction it updates the file. So even after closing the program, the data is not lost.

Account numbers are generated automatically starting from 1001, which ensures every account has a unique number. The system also follows a banking rule that a minimum balance of Rs. 500 must always remain in the account. If a withdrawal or transfer breaks this rule, the transaction is cancelled.

*Key Features:*
1. *Create Account:* Create a new account with name and opening deposit.
2. *Deposit:* Add money to an existing account.
3. *Withdraw:* Withdraw money while maintaining minimum balance.
4. *Transfer:* Transfer money from one account to another account.
5. *Balance Enquiry:* Check the current balance of any account.
6. *File Handling:* All data is saved in .py simple banking system` using file handling.

*Concepts Used:*
- Loops
- Functions
- Conditions (if-else)
- File Handling

*Software Requirements:*
- Python 3
- Any Code Editor / Pydroid / VS Code
- Console / Terminal to run the program

*How it Works:*
1. User selects an option from the menu.
2. Program calls the respective function for that option.
3. Function loads data from.py simple bankingsystem, performs validation, updates balance, and saves data back to the file.
4. Output is displayed on the console.
